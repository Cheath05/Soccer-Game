# Data attribution and usage

This is a personal, local, non-distributed project. Third-party datasets are downloaded into `data/raw/`, which is gitignored and never committed.

| Source | Licence / terms | Our use |
|---|---|---|
| transfermarkt-datasets (dcaribou) | CC0-1.0 (content originates from Transfermarkt) | World skeleton: clubs, players, contracts, values, transfers |
| EA SPORTS FC ratings (user-provided file) | EA intellectual property; not redistributable | Optional local ratings import only. Never scraped, never committed. |
| StatsBomb Open Data | Free with attribution to StatsBomb | Fitting calibration parameters (xG, passing, xT) |
| Wyscout public dataset (Pappalardo et al., 2019) | CC BY 4.0 | Calibrating league-level action distributions |
| SkillCorner Open Data | MIT; credit SkillCorner | Movement/shape calibration |
| football-data.co.uk | Free use with attribution | Result distribution targets |
| ClubElo | Free API | Club strength priors |

Club crests and league logos are not used.
